# Guides

Operational how-tos: running locally, deploying, onboarding, recovering from something.

Empty on purpose. A guide is written when someone has actually done the thing and the
steps are known — not in advance.

Until then, the real instructions live where they already are:

- Running and configuring: the project `README.md`.
- The development loop and who does what: `docs/HOW_TO_DEVELOP.md`.
- Every command: `make` on its own.
