# Architecture overview

One-page map of the system. Grows as the project does.

## What it is

A parametric thread and fastener generator — screws, bolts, nuts, threaded rods. One
validated parameter set will produce a live 3D preview, the dimensions you would measure
on the finished part, and an STL or STEP download, reachable three ways — web UI, HTTP
API, CLI — from one parameter model. The sibling of `spur` (gears), built to the same
rules (L02).

## Stack

Python 3.12, FastAPI + Pydantic v2, uvicorn; CadQuery over OpenCascade; pytest; Docker and
GitHub Actions. Why → `L01`. A viewer, when it arrives, is vanilla JS + vendored three.js.

## Main pieces

**Nothing is built yet** (2026-10-05). `src/screw/` holds the package stub the gate
installs; `tests/test_smoke.py` proves the harness is wired. The shape below is the intent
gsd plans against, mirroring spur; it becomes a table of real modules as they land, and
each real subsystem gets its own `architecture/<subsystem>/` once a single file stops
holding it.

- **Parameters** — one validated, frozen, hashable model; validated once at the boundary
  and trusted afterwards. Its JSON schema builds the web form and the CLI flags.
- **Thread maths** — pure arithmetic, no CAD kernel import, ever: it runs on every
  keystroke. Derived dimensions, measurement aids, feasibility, warnings.
- **Solid model** — the only module that imports `cadquery`/`OCP`. Vendor types stop here.
- **HTTP API + UI serving**, **Web UI**, **CLI** — three front ends on the one model.
- **Packaging** — the image and the checks that keep it honest.

The dependency direction will be enforced, not hoped for: `pyproject.toml` carries the
import-linter contracts and `make verify` fails on a violation. Today there is one ("the
app never imports its own tests"); the kernel-boundary contract is added in the same commit
as the first maths module.

## Source of truth

- **The part** — nothing is stored. Every answer is derived from the parameters on demand;
  any cache is a speed optimisation and safe to lose.
- **The parameters** — the URL. A model link carries its full parameter set, which is why
  defaults are frozen (L02).
- **The dependency closure** — `requirements.txt`, generated by `make lock` (L06).
- **Decisions** — `decision_log.md`. **Per-phase intent** — gsd's `.planning/`.
