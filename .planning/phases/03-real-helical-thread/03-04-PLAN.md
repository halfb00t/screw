## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form — run `/gsd-mvp-phase 3` to restate it; no story
is invented here): A user who sets `d`, `pitch` and `length` in explicit millimetres gets a bolt-kind
solid carrying a real ISO 68-1 helical thread, right- or left-hand, on all three front ends, and a
build the postcondition rejects never reaches a cache, a preview or a download.

<objective>
Expansion slice 3: the user can ask for a left-hand thread on the API and the CLI (the page's checkbox
is plan 03-05) and gets one, proven left-handed by a probe the volume gate cannot replace; and a
request or command that names a parameter twice is refused naming it instead of silently keeping one.

Purpose: THRD-02 and D-09; D-12, which lands the duplicate-flag refusal in the same flag-generator
change that adds `BooleanOptionalAction`.
Output: the field, the builder wiring, the CLI actions, the app-level dependency, tests, the
repeated-key debt item retired.
</objective>
