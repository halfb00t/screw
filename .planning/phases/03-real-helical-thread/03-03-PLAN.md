## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form — run `/gsd-mvp-phase 3` to restate it; no story
is invented here): A user who sets `d`, `pitch` and `length` in explicit millimetres gets a bolt-kind
solid carrying a real ISO 68-1 helical thread, right- or left-hand, on all three front ends, and a
build the postcondition rejects never reaches a cache, a preview or a download.

<objective>
Expansion slice 2: a user who asks for a fine STL that L11 measured over the export budget is told so,
by the same kernel-free rule on the API and the CLI and as a warning on the info document, instead of
waiting for a blob that is rebuilt on every request because it never fits the bytes cache.

Purpose: D-02 and D-03 — L11's bytes caps applied as a refusal of one artefact, only on the rows that
were measured.
Output: the L11 row table, one rule, its two front-end call sites, tests.
</objective>
