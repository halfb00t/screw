## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form — run `/gsd-mvp-phase 3` to restate it; no story
is invented here): A user who sets `d`, `pitch` and `length` in explicit millimetres gets a bolt-kind
solid carrying a real ISO 68-1 helical thread, right- or left-hand, on all three front ends, and a
build the postcondition rejects never reaches a cache, a preview or a download.

<objective>
Expansion slice 1: the user is told, at the model boundary and before any build, when a thread cannot
be made (root radius not above 0) or was never measured (more than 250 turns), with a 422 the page
already highlights; and the info document stops describing a cylinder: turns, the thread's closed-form
volume, depth and minor diameter, and the new standing warning.

Purpose: D-01, D-04, D-05, D-06 — the kernel only ever sees a (d, pitch, length) inside the measured
construction cap, and every printed number is one the pinned profile gives.
Output: four kernel-free rules, two validators, the D-05 document, tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> params | every query value and CLI flag is untrusted until `BoltParams` validated it; the model is the one place it is checked (AGENTS.md) |
| params -> kernel | a validated set is trusted by the pool and the builder; anything the kernel cannot model must be refused here or at the builder doorway |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-3-04 | Denial of service | `BoltParams` -> pool | high | mitigate | 250-turn cap by exact decimal arithmetic before the pool (Task 1): a request for 1e5 turns is a 422 in microseconds instead of a worker held to the 30 s timeout |
| T-3-05 | Denial of service | `FastenerParams` -> `helical.section` | high | mitigate | Root-radius refusal (Task 1): a negative root radius never builds a self-crossing section the kernel may crash on |
| T-3-06 | Information disclosure | `derive` rows | medium | mitigate | Turns from exact decimals, volume from the closed form, non-finite computed rows withheld with a warning (Task 2); a printed number is one someone can cut metal to (L02) |
| T-3-SC | Tampering | npm/pip/cargo installs | low | accept | No package installed or added (03-RESEARCH Package Legitimacy Audit: none) |
