## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form): For any bolt a user can get the matching ISO 4032
nut at a chosen radial clearance, see the pair's numbers on the info panel, and get a kernel verdict on
whether the pair mates, one that cannot report `proven` when its own control did not fire.

<objective>
Ship the ISO 4032:2023 rows under the Phase 4 ruling-B double entry: the agent's transcription from page
images first, then the owner's copy, the cell-by-cell diff, one relation test per row, the frozen-default
row test. Output: `HexNut`, `tables/iso4032.py`, the owner copy, the tests. The catalogue and the panel
read these rows in 05-07 and 05-09.
</objective>
