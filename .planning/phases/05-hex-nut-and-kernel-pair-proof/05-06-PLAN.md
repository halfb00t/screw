## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form): For any bolt a user can get the matching ISO 4032
nut at a chosen radial clearance, see the pair's numbers on the info panel, and get a kernel verdict on
whether the pair mates, one that cannot report `proven` when its own control did not fire.

<objective>
Ship the GOST ISO 4032-2014 (ISO 4032:2012) nut rows, which L14 reads in place of a purchased ISO 4032
copy, under the Phase 4 ruling-B double entry: the agent's transcription from page images first, then the
owner's copy (generated from the PDF's text layer, labels fixed by the owner), the cell-by-cell diff, one
relation test per row, the frozen-default row test. Output: `HexNut`, `Source.document()`,
`tables/iso4032.py`, the owner copy, the tests. The catalogue and the panel read these rows in 05-07 and
05-09.
</objective>
