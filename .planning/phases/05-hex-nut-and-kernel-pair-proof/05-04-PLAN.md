## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so no story is invented): For any bolt a user can
get the matching ISO 4032 nut at a chosen radial clearance, see the pair's numbers on the info panel,
and get a kernel verdict on whether the pair mates, one that cannot report `proven` when its own control
did not fire.

<objective>
The tracer. A user who types a clearance gets a nut: `params` (NutParams, required clearance) -> `calc`
(the nut's rows and closed form) -> `solid` (hex prism less the L11 void, two gates) -> the API routes,
the CLI and the pool, with the page's kind selector listing it from `/api/kinds`. One thin path; the
nut's refusals are 05-05, its rows 05-06 onward, its ends 05-13.

Purpose: prove the second kind end to end, and the registry with a required field, before any table or
end model is layered on it. Registering the kind breaks every test that assumes one kind or a
defaults-only model (RESEARCH Codebase Map); each break is fixed in the same green commit.
Output: the nut kind on every front end and the tests that pin it.

Scope: two tasks, 18 files; the tracer commit touches 17 because a second, required-field kind breaks
the registry-wide tests and each is fixed in the same commit (`make verify` on every commit, the 04-03
precedent). Estimate 150000 raw tokens against the 100000 budget: the atomic registration cannot split.
</objective>
