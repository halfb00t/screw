## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form): For any bolt a user can get the matching ISO 4032
nut at a chosen radial clearance, see the pair's numbers on the info panel, and get a kernel verdict on
whether the pair mates, one that cannot report `proven` when its own control did not fire.

<objective>
Land the pre-registration on main before any run it pre-registers: the other CLI reviews PR A, the
findings become commits, `make pr.land` squash-merges it, and the phase branch merges origin/main so the
expected table and the M18 protocol are on the branch every later plan works on.

Purpose: SC3 and SC6 are checkable only if the order is visible on main (D-08, 02 D-19). Output: PR A
merged, the phase branch carrying it.
</objective>
