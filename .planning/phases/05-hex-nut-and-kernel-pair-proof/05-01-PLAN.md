## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so MVP mode frames no story here; run
`/gsd-mvp-phase 5` if the owner wants it restated): For any bolt a user can get the matching ISO 4032
nut at a chosen radial clearance, see the pair's numbers on the info panel, and get a kernel verdict
on whether the pair mates, one that cannot report `proven` when its own control did not fire.

<objective>
Pre-register the two kernel runs this phase makes, on their own PR, before any run exists: the
expected verdict of every recorded pair cell (D-07, derived by a script from `2026-10-08-a-pair`, never
typed) and the bounded M18 control diagnosis (D-08: Question, Environment, Method, Predictions, Escape
clause, plus the probe that reads exactly what the protocol fixes). Both must be visibly on `main`
before the pair tier or the probe runs, and `make pr.land` squashes, so they ship as PR A (02 D-19
precedent, RESEARCH P15). Plan 05-03 has the other CLI review it and lands it.

Purpose: SC3 and SC6 are only checkable if the expectations and the diagnosis method predate the
data on `main`. Output: the deriving script and its table, the protocol and its probe, the tests, one
open PR.

Scope: three tasks. Work happens in a separate worktree on a branch cut from `origin/main`, so the
main checkout (and this plan file) stays on the phase branch the whole time: switching the main
checkout to a branch without `.planning/phases/05-*` would delete the plan files from under the
executor. `make worktree.new` does not fit: it branches `agent/<slug>` off the current HEAD (the
phase branch, which carries the local planning commits origin/main lacks), and PR A must be cut
from origin/main, so step 1 of Task 1 calls `git worktree add` directly.

Where checks run: the test runs (`make test`, `make verify`) happen inside the worktree, in the
task actions, and the pre-commit hook re-runs `make verify` there on every commit. Every
`<automated>` check runs from the main checkout root and reads the branch through git
(`git show gsd/phase-05-preregistration:<path>`, `git log`, `git diff` against origin/main),
because the worktree directory does not exist when the plan is checked.
</objective>
