## Decisions this plan makes, and why

- **Match the fields client-side on a failure; do not special-case the clearance.** The 422 for a missing clearance carries no `preset`. So on any failure the page has no info document saying which row the part is, and today it blanks the selects (`showMatch(null)`). D-12 says the selects track the fields. The page already holds the catalogue (`catalogue.rows[].fields`) and the controls, and the server's rule is exact float equality, first row in catalogue order (`calc.presets.match` and `match_nut` docstrings). `catalogue_document` lists the rows in the order `match` walks them. So the page can answer "which row do these fields hold" itself, by the same rule, for every failure and every kind, with no field or kind name.
  - The other option, keeping the pick only when the 422 names fields the row does not define, needs the page to parse which fields a refusal names. It also leaves the selects blank after any other failure even when the fields are a row. It is more code and covers less.
  - Equality is `Number(read(input)) === value` on the JSON number. The form string and the query string parse to the same IEEE double that pydantic reads. An empty control never matches: `Number('')` is 0, and rule 35 warns about exactly that.
  - Each row's fields read back as its own id on the server (`tests/test_presets.py::test_every_catalogue_row_round_trips`; `tests/test_calc.py` line 317 for the nut). So the first equal row is never another row with the same fields.
- **The badge stays empty after a failure.** The badge composes from `info.preset` (rule 33), and a failed update has no info document. Only the selects change. `presetBasis` is still set by a pick or an exact info document, never by this match.
- **The default nut now opens with ISO 4032 / M6 in the selects.** Its frozen fields are the M6 row (D-15), so after the fix the first failed update shows that row. That is "the selects track the fields" (D-12), and the probe pins it.
- **The reproduction is a scratch browser probe, not a gate test.** The repo tests app.js only as text (`tests/test_parity.py` docstring: "It holds no browser (L01)"; 01-UI-SPEC.md Verification status: "no browser is in the gate (L01)").
  - Phase 4 set the precedent for scratch instruments outside the repo: 04-13's throwaway node harness and 04-17's headless-Chrome CDP probe.
  - The probe runs on the Playwright already installed in the sibling spur checkout's venv (`playwright` 1.63.0 with `chromium_headless_shell-1243`). Nothing is installed and screw gains no dependency.
  - A committed browser test is a decision for the owner (Task 3 files it), as the orchestrator required.

"""G-05-1 reproduction probe: scratch evidence, not a test and not in the repo (L01)."""
import json
import os
import sys
from pathlib import Path

from playwright.sync_api import sync_playwright

BASE = sys.argv[1]  # e.g. http://127.0.0.1:8011/
OVERRIDE = os.environ.get("SCREW_PROBE_APP_JS")  # planner grounding only; unset in the plan run
STATE = """() => ({
  selects: [...document.querySelectorAll('#picker select')].map(s => s.value),
  sizes: [...(document.querySelectorAll('#picker select')[1]?.options ?? [])].map(o => o.value),
  fields: Object.fromEntries([...document.querySelectorAll('#params input')].map(
    i => [i.name, i.type === 'checkbox' ? String(i.checked) : i.value])),
  status: document.querySelector('#status').textContent,
  dims: document.querySelector('#dims').children.length,
  disabled: [...document.querySelectorAll('.downloads a')].map(a => a.getAttribute('aria-disabled')),
  errors: [...document.querySelectorAll('#messages p.error')].map(p => p.textContent),
})"""
M2 = {"d": "2", "pitch": "0.4", "s": "4", "m": "1.6", "clearance": ""}
M6 = {"d": "6", "pitch": "1", "s": "10", "m": "5.2", "clearance": ""}
failed = []


def check(step, page, selects, fields):
    st = page.evaluate(STATE)
    got = {k: st["fields"].get(k) for k in fields}
    ok = (st["selects"] == selects and got == fields and st["status"] == "" and st["dims"] == 0
          and st["disabled"] == ["true", "true"] and stl == [])
    print(("PASS " if ok else "FAIL ") + step, json.dumps(st))
    if not ok:
        failed.append(step)


with sync_playwright() as pw:
    browser = pw.chromium.launch()
    page = browser.new_page()
    if OVERRIDE:
        body = Path(OVERRIDE).read_text()
        page.route("**/static/app.js", lambda r: r.fulfill(content_type="text/javascript", body=body))
    stl = []
    with page.expect_response(lambda r: "/api/bolt/model.stl" in r.url and r.status == 200, timeout=60000):
        page.goto(BASE)
    page.on("request", lambda r: stl.append(r.url) if "/api/nut/model.stl" in r.url else None)
    page.select_option("#kind", "nut")
    page.wait_for_timeout(3000)
    check("open nut: the selects follow the default fields", page, ["ISO 4032", "M6"], M6)
    page.fill("input[name=d]", "6.5")
    page.wait_for_timeout(2500)
    check("d 6.5: no row, blank selects", page, ["", ""], {**M6, "d": "6.5"})
    page.select_option("#picker select >> nth=0", "ISO 4032")
    page.wait_for_timeout(2500)
    check("pick ISO 4032: the selects keep ISO 4032 / M2", page, ["ISO 4032", "M2"], M2)
    if "M6" in page.evaluate(STATE)["sizes"]:
        page.select_option("#picker select >> nth=1", "M6")
        page.wait_for_timeout(2500)
        check("pick M6: the selects keep ISO 4032 / M6", page, ["ISO 4032", "M6"], M6)
    else:
        print("FAIL pick M6: M6 is not offered in Size", page.evaluate(STATE)["sizes"])
        failed.append("pick M6")
    browser.close()
print("RESULT", "FAIL" if failed else "PASS", failed)
sys.exit(1 if failed else 0)
