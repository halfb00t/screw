## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form): For any bolt a user can get the matching ISO 4032
nut at a chosen radial clearance, see the pair's numbers on the info panel, and get a kernel verdict on
whether the pair mates, one that cannot report `proven` when its own control did not fire.

<objective>
The nut's catalogue and exact match: a user picks `ISO 4032 M6` (or an Annex A size, labelled) on the
page, the API or the CLI and gets the row's millimetre fields, and a nut that is a row reads its cited
values, designation and notes. Output: nut preset rows, per-kind dispatch in `calc/presets.py`, the nut
panel's cited rows, tests.
</objective>
