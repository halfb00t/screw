## Decisions this plan makes, and why

The ruling fixed what is carried. These are the choices left to the planner.

- **The memory is generic: per kind, each field with no default.** app.js may not name a field or a kind (D-10, rule 29). `tests/test_parity.py` fails on a quoted `'clearance'` or `'nut'`. A field with no default is the class D-01 created and rule 35 names. Today only the nut's `clearance` is in it, so the generic rule is exactly the owner's ruling. Fields that have a default are never remembered: carrying a typed `s` or `m` would override the counterpart's row values and D-03's frozen defaults.
- **"Typed" means an `input` event on the control.** A value written by a link (`navigate`), Reset or a kind change is not typed, so it is not remembered. Typing the field empty forgets the value; a link never carries an empty or stale number. This is the ruling's word "typed", read literally. The amendment says so, so the owner can see it.
- **Page memory, not storage.** A module-level `Map`, so "this tab" is this page's lifetime. A reload forgets it, as does a new tab. CODING_VALUES State says nothing is persisted, and sessionStorage would be persistence the ruling did not ask for.
- **The server's fields go last in the link.** `{ kind, ...typed, ...counterpart.fields }`, so no remembered value can override a field the server names. None can collide today, because D-02 never names `clearance`.
- **The info document does not change.** The ruling is about the page's link. `PartInfo.counterpart` is a published shape (D-02, costly), and the CLI and API stay the same.

"""G-05-3 reproduction probe: scratch evidence, not a test and not in the repo (L01)."""
import json
import os
import sys
from pathlib import Path

from playwright.sync_api import sync_playwright

BASE = sys.argv[1]  # e.g. http://127.0.0.1:8011/
OVERRIDE = os.environ.get("SCREW_PROBE_APP_JS")  # planner grounding only; unset in the plan run
LINK = "() => document.querySelector('#counterpart').hidden ? null : document.querySelector('#counterpart').getAttribute('href')"
failed = []


def check(step, ok, detail):
    print(("PASS " if ok else "FAIL ") + step, json.dumps(detail))
    if not ok:
        failed.append(step)


def new_page(browser, seen):
    page = browser.new_page()
    if OVERRIDE:
        body = Path(OVERRIDE).read_text()
        page.route("**/static/app.js", lambda r: r.fulfill(content_type="text/javascript", body=body))
    page.on("response", lambda r: seen.append((r.status, r.url.split("/api/", 1)[1])) if "/api/" in r.url else None)
    return page


def built(page, kind):
    return page.expect_response(lambda r: f"/api/{kind}/model.stl" in r.url and r.status == 200, timeout=60000)


with sync_playwright() as pw:
    browser = pw.chromium.launch()
    seen = []
    page = new_page(browser, seen)
    page.goto(BASE + "#kind=nut")
    page.wait_for_selector("#picker select")
    with built(page, "nut"):
        page.fill("input[name=clearance]", "0.1")
    seen.clear()
    with built(page, "bolt"):
        page.click("#counterpart")
    page.wait_for_timeout(500)
    href = page.evaluate(LINK) or ""
    bolt_urls = [u for _, u in seen if u.startswith("bolt/")]
    check("bolt: Matching nut carries the typed clearance", "clearance=0.1" in href and href.startswith("#kind=nut&"), href)
    check("bolt: its hash and its requests carry no clearance",
          "clearance" not in page.evaluate("location.hash") and not any("clearance" in u for u in bolt_urls),
          {"hash": page.evaluate("location.hash"), "bolt": bolt_urls})
    seen.clear()
    page.click("#counterpart")
    page.wait_for_timeout(10000)
    value = page.input_value("input[name=clearance]")
    nut_stl = [s for s, u in seen if u.startswith("nut/model.stl")]
    check("nut again: opens with clearance 0.1 and builds", value == "0.1" and nut_stl == [200],
          {"clearance": value, "nut_stl": nut_stl})
    page.fill("input[name=clearance]", "")
    page.wait_for_timeout(2500)
    with built(page, "bolt"):
        page.select_option("#kind", "bolt")
    page.wait_for_timeout(500)
    href = page.evaluate(LINK) or ""
    check("cleared: a clearance typed empty is forgotten", "clearance" not in href and href.startswith("#kind=nut&"), href)
    fresh = new_page(browser, [])
    with built(fresh, "bolt"):
        fresh.goto(BASE)
    fresh.wait_for_timeout(500)
    href = fresh.evaluate(LINK) or ""
    check("fresh page: no clearance typed, none carried", href == "#kind=nut&d=6&pitch=1&left_hand=false&s=10&m=5.2", href)
    browser.close()
print("RESULT", "FAIL" if failed else "PASS", failed)
sys.exit(1 if failed else 0)
