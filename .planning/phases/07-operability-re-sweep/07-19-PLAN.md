linux/amd64 over the full grid, or is capped and warned or refused with a `422`, and every runtime

missing for its head, computed from the diff. Log both tiers as L24 and the merge rule as L25.

the run the trigger starts, and one path list, held equal by a test, decides both.

fixtures, L24, L25.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR code -> runner (full tier) | a pull_request run executes the PR's code |
| schedule -> main | the weekly run measures main |
| PR author -> merge gate | the author controls the PR's workflow file and its paths filter |
| gh API -> pr.land | the files and runs reads decide whether a merge happens |
