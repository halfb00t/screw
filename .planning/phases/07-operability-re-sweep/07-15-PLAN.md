## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so the MVP user-story framing is not invented
here): Every configuration a user is allowed to ask for builds inside a per-build timeout measured on
linux/amd64 over the full grid, or is capped and warned or refused with a `422`, and every runtime
bound cites the run that set it.

Spec-less probe fallback applied: the OPER-02 boundary edge (a capped N has no figure and does not
qualify) is the last truth.

<objective>
Run the second campaign on the admitted set the owner's budget defines: the worst admitted builds with
every worker busy at 1, 2 and 3 workers, the memory probes, the load sweep and the gzip readings, each
at 5 reps; then re-check the envelope against every new reading.

Purpose: D-09's timeouts, D-03's worker pick, D-02's mem_limit and the discretion knobs all come from
these records. Output: Runs II records and RESULTS, an envelope that covers them.
</objective>
