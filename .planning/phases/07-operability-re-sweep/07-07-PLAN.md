## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so the MVP user-story framing is not invented
here): Every configuration a user is allowed to ask for builds inside a per-build timeout measured on
linux/amd64 over the full grid, or is capped and warned or refused with a `422`, and every runtime
bound cites the run that set it.

Spec-less probe fallback applied: the OPER-03 adjacency edge at the root floor (exactly at the floor
is accepted, just below is refused) is the second truth.

and the new root-radius floor, each computed by the pre-registered rule from runner records, written
into the code with its run, and logged as L20. Close or update the debt and the idea that waited for
this.

Purpose: D-08 and D-18. The cost model (07-11) bounds cost inside these walls; the walls bound what
the kernel can do at all. Output: cited constants, the floor in the three root rules, L20.
</objective>
