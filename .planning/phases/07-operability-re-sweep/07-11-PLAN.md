## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so the MVP user-story framing is not invented
here): Every configuration a user is allowed to ask for builds inside a per-build timeout measured on
linux/amd64 over the full grid, or is capped and warned or refused with a `422`, and every runtime
bound cites the run that set it.

Spec-less probe fallback applied: the OPER-03 adjacency (at the budget admitted), empty (all-default
parts admitted) and ordering (one warning per refused artifact, in `_DOWNLOADS` order) edges are truths
2, 6 and 7.

<objective>
Ship the cost model: the fitted, enveloped, kernel-free predictor in `calc`, judging each artifact of
either kind against the ruled budget, through the one refusal function every front end already shares,
with the ruled 422 shape.

Purpose: D-05 to D-08 and D-17. This is what makes "every configuration a user may ask for" bounded.
Output: `calc/cost.py` complete, `download_refusal` delegating, the 422 shape, moved pins.
</objective>
