## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so the MVP user-story framing is not invented
here): Every configuration a user is allowed to ask for builds inside a per-build timeout measured on
linux/amd64 over the full grid, or is capped and warned or refused with a `422`, and every runtime
bound cites the run that set it.

Spec-less probe fallback applied: the OPER-02 boundary edge (N = 1) is the last truth.

<objective>
Build the Runs II instruments that answer D-09 and the memory knobs: a contention driver that keeps
every worker busy while the worst admitted point builds, and three memory probes (solid cache size,
arena release, drift over a second pass). The bound and memory sets themselves are generated in plan
07-15, once the budget is ruled; this plan proves the instruments with a smoke set.

Purpose: D-09's timeout and D-02's mem_limit need numbers no Runs I reading gives (Pitfall 2: the old
memory driver never had more than one build in flight). Output: `bench/oper_bound.py`, the parent's
two new point kinds, a runner smoke.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-15 | Denial of service | contention container | medium | mitigate | the same `--memory` cap and deadline as every reading; a bound point past the deadline is `killed` and its processes terminated |
| T-07-16 | Tampering | `env` in point files | medium | mitigate | allow-list of `SCREW_SOLID_CACHE` only, values 1..4, passed as argv elements (no shell); tested |
| T-07-17 | Tampering | memory figure from a scaled single reading | high | mitigate | every N and K is its own container reading; the prohibition is tested by the absence of any multiplication path in the drivers (review) and by R16's measured terms |
| T-07-SC | Tampering | package installs | low | accept | no package is installed or added |
