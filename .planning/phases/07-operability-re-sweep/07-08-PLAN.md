## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so the MVP user-story framing is not invented
here): Every configuration a user is allowed to ask for builds inside a per-build timeout measured on
linux/amd64 over the full grid, or is capped and warned or refused with a `422`, and every runtime
bound cites the run that set it.

Spec-less probe fallback applied: the OPER-02 empty edge (fewer than 20 samples give no p95) is the
fourth truth.

<objective>
Build the last Runs II instruments: an HTTP load driver against the server in the production image
(workers, queue depth, Retry-After, SCREW_WORKERS, HEALTHCHECK, mem_limit), the JSON-body measurement
for gzip's `minimum_size`, and per-level gzip readings. Prove them with a runner smoke.

Purpose: D-03's worker pick and the discretion knobs need concurrent serving figures (Pitfall 2).
Output: `bench/oper_load.py`, `bench/oper_serve.py`, the `load` point kind, `gzip_levels`, a smoke.
</objective>
