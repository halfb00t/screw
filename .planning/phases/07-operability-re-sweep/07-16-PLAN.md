## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so the MVP user-story framing is not invented
here): Every configuration a user is allowed to ask for builds inside a per-build timeout measured on
linux/amd64 over the full grid, or is capped and warned or refused with a `422`, and every runtime
bound cites the run that set it.

Spec-less probe fallback applied: the OPER-02 precision edge (ceil for timeouts and Retry-After, whole
bytes, MiB and seconds rounded up by the stated rule) is in truths 3 to 5.

<objective>
Derive every runtime value from the records by the pre-registered rules, and write them into the code:
the three timeouts, Retry-After, the worker count, the queue depth, gzip, the caches, the arenas, the
recycling decision and the server process count.

Purpose: OPER-01 and OPER-02's "measured and cited". Output: runtime.json and the constants that equal
it.
</objective>
