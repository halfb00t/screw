## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so the MVP user-story framing is not invented
here): Every configuration a user is allowed to ask for builds inside a per-build timeout measured on
linux/amd64 over the full grid, or is capped and warned or refused with a `422`, and every runtime
bound cites the run that set it.

<objective>
Add the required tier of D-12: a ~10-minute boundary set built in the production image on every PR
and push to main, failing on any timeout overrun or under-prediction, required by `make pr.land`.

Purpose: OPER-03's "a CI job proves it", on every change. Output: the boundary file, `bench.oper
check`, the `bounds` job, its required-jobs entry, a green run on a draft PR.
</objective>
