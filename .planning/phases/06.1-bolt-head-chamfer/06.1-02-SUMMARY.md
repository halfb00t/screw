# Phase 06.1 Plan 02: head_chamfer field and the cut Summary

**`head_chamfer` (degrees, default 30, 0 = sharp) now reaches the web form, the API and the CLI from one field; the head's top corners are cut by a cone from s / 2 on the head prism, judged at T_PIECE by their own volume, then the whole bolt at T_GATE against the closed form less the same term.**

## Performance

- **Duration:** about 45 min (two pre-commit `make verify` runs of 4:36 and 3:11, one manual run of 2:52)
- **Completed:** 2026-10-24T11:44Z
- **Tasks:** 2
- **Files modified:** 11 (377 insertions, 65 deletions)

## Accomplishments

- Field: `_angle` helper beside `_free`, `BoltParams.head_chamfer = _angle(30.0, ge=0, lt=90, ...)` declared last. Schema property is `{minimum 0, exclusiveMaximum 90, group Head, unit degrees, step 0.5, default 30.0}`; `GET /api/bolt/info?head_chamfer=90` is a 422 at `["query", "head_chamfer"]`. `.venv/bin/python -m screw info bolt --head-chamfer 0` reports the sharp volume exactly, so the CLI flag exists with no per-field code.
- Kernel: `bolt.head_prism`, `bolt.chamfer_head` (the nut's `face_chamfer` profile mirrored to the head's top face, result left as a Compound), `bolt.assemble(p, thread, head=None)`. `_build_bolt` cuts and gates the head before the fuse; the measurement that placed it is in the code comment. `bench/`, `solid/pair.py` and `solid/nut.py` are untouched.
- Closed form: `bolt_end_closed_volume` takes a required trailing `head_chamfer`, so no caller can print a sharp volume for a chamfered part. The info volume row and its "not reported" formula text name the head chamfer.
- Default part changed as ruled (D-15): the closed form is 1.0855309493921927 mm3 less, the default slug is `bolt_d6_pitch1_left_hand0_length20_s10_k4_thread_length20_head_chamfer30`, and the kernel-failure text ends "thread_length and head_chamfer."
- Edges (Task 2) on macOS arm64: 0.5, 89.9, 1e-4 and 89.99999999999999 degrees build inside both gates; 1e-6 is refused as a BuildError ("Geometry kernel failed (Standard_Failure)"); 5e-324 is refused as a BuildError (the oracle's ValueError). None is a 500, and `derive` reports no volume row and a "volume not reported ... head chamfer" warning for 5e-324.
