## Phase Goal

ROADMAP **Goal** (verbatim): A bolt or screw (ISO 4014, ISO 4017) gets a chamfered hex head: one
`head_chamfer` field, an angle in degrees, default 30, where 0 builds the sharp head of today. The
chamfer is a cone from the inscribed circle `s / 2` on the top face only, the same stated model as the
nut face chamfer (L15, R4 a), so it clips the six corners; the bearing face is unchanged. The head's
closed form stays exact for the cone-clipped prism, the field ships on UI, API and CLI with its tests,
and a new decision-log entry supersedes L13 D-01's "no top chamfer".

<objective>
The field ships and the head is cut. Task 1 (tracer) wires `head_chamfer` from the model through the
kernel cut, its own piece gate and the whole-part closed form to the info document's volume row, the
API and the CLI, and updates every test that pinned the old default part in the same commit. Task 2
proves the edges: a capped direct construction (D-06), tiny and near-right angles (D-18), and the pair
proof's evidence bolt (D-17).

Purpose: the default part changes (D-15, owner ruling 2026-10-24), and the pre-commit hook runs `make
verify`, so the field, the cut, the closed form and every pin of the old default land as one commit.
That is why Task 1 touches ten files: a smaller commit would leave the suite red or a field that does
nothing. Output: a chamfered default head on every front end, tested at both gates.
</objective>
