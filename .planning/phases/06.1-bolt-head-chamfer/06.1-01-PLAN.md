## Phase Goal

ROADMAP **Goal** (verbatim): A bolt or screw (ISO 4014, ISO 4017) gets a chamfered hex head: one
`head_chamfer` field, an angle in degrees, default 30, where 0 builds the sharp head of today. The
chamfer is a cone from the inscribed circle `s / 2` on the top face only, the same stated model as the
nut face chamfer (L15, R4 a), so it clips the six corners; the bearing face is unchanged. The head's
closed form stays exact for the cone-clipped prism, the field ships on UI, API and CLI with its tests,
and a new decision-log entry supersedes L13 D-01's "no top chamfer".

No requirement id is mapped (ROADMAP: Requirements TBD); this plan covers D-02, D-03, D-04 (the pure
predicate and text), D-05 (the pure rule), D-07 and D-08. Spec-less probe fallback skipped: the phase
has no requirement ids to probe and no SPEC.md (a visible, recorded choice).

<objective>
The kernel-free maths of the head chamfer, in `screw.calc.thread`, before any field or kernel uses it.
Task 1 (tracer) lands the one shared depth predicate and the analytic closed form, pinned against both
existing oracles at the default part and over a grid. Task 2 lands the band constant, the band and cap
warnings and the request-boundary conflict text, all calling the same predicate.

Purpose: D-07 makes "exact" in the roadmap mean exact, and every later plan (builder, closed form,
info document, 422 rule) calls these functions, so they cannot disagree at the cap boundary.
Output: five new names in `src/screw/calc/thread.py` and their tests. No field, no behaviour change:
nothing in `src/` calls them yet, so the default part is unchanged by this plan.
</objective>
