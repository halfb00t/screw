## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| query string / argv -> BoltParams | untrusted `head_chamfer` text crosses here and is validated once | untrusted numeric text |
| raw query / argv -> explicit-conflict rule | untrusted strings parsed to floats (nan and inf included) reach the rule before the model | untrusted floats |
| request values -> pure maths | validated model values and raw request floats feed `screw.calc.thread` | floats, possibly non-finite |
| BoltParams -> worker kernel | a validated angle drives a boolean cut and two precise volumes in the worker | validated float, CPU cost |
| slug -> Content-Disposition and temp file names | the new field's value enters a file name | validated float printed `%g` |
| derive() -> page, API, CLI | rows, notes and warnings built from validated floats reach three front ends | numbers and module-constant text |
| `--preset` expansion -> rule | preset row values are merged under the user's flags before the rule | catalogue values |
