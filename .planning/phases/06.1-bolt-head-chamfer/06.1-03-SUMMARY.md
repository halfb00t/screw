# Phase 06.1 Plan 03: head chamfer on the info document Summary

**The info document now says what was cut: four Head rows (angle, depth as cut, chamfer circle, edge left) on a chamfered bolt, a sharp-head note at 0, band and cap warnings for off-band and over-deep angles, and a standing warning that names the hex head chamfer and L19 - identically on the page, the API and the CLI because all three read `derive()`.**

## Performance

- **Duration:** about 15 min (three pre-commit `make verify` runs inside the commits, one manual run of 2:29)
- **Completed:** 2026-10-24
- **Tasks:** 2
- **Files modified:** 5 (166 insertions, 22 deletions)

## Accomplishments

- Rows (Task 1, tracer): `_bolt` splices four tuples into `computed` right after `k`, only when `head_chamfer > 0`. The existing loop places the matched row's cited head values after `k`, so the default document's Head group is contiguous and ends `... dw_min, head_chamfer, chamfer_depth, chamfer_circle_diameter, corner_edge_left`, then `volume`. At 80 degrees the depth row reads 2.0 and the edge left 2.0, not the 4.39 mm model depth.
- Note: `SHARP_HEAD_NOTE` ("sharp hex head corners: head_chamfer 0 cuts no top chamfer (L19)") is appended to the notes of every bolt with `not head_chamfer > 0`, including a part that matches no row, where it is the only note. `PartInfo.notes` description reworded to say so.
- Warnings (Task 2): `head_chamfer_warnings(p.s, p.k, p.head_chamfer)` runs inside `contextlib.suppress(OverflowError, ValueError)` directly before `NO_ROW_WARNING`. A defaulted 30 on `s = 100` reads `[standing, cap text, NO_ROW]`; a direct 80 builds and reads `[standing, band, cap]` (D-06, not refused).
- Standing warning: `STANDING_WARNING` is the D-12 text; its comment names L15 and L19 and keeps the release note. The three pins (`tests/test_calc.py`, `tests/test_cli.py` with its "warning: " prefix, `tests/test_parity.py`) are the literal.
- No front-end file was touched: the page renders `info.rows`, `info.notes` and `info.warnings` generically, and the CLI prints the same document.
