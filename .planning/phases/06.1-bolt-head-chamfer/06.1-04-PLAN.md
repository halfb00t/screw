## Phase Goal

ROADMAP **Goal** (verbatim): A bolt or screw (ISO 4014, ISO 4017) gets a chamfered hex head: one
`head_chamfer` field, an angle in degrees, default 30, where 0 builds the sharp head of today. The
chamfer is a cone from the inscribed circle `s / 2` on the top face only, the same stated model as the
nut face chamfer (L15, R4 a), so it clips the six corners; the bearing face is unchanged. The head's
closed form stays exact for the cone-clipped prism, the field ships on UI, API and CLI with its tests,
and a new decision-log entry supersedes L13 D-01's "no top chamfer".

<objective>
The request boundary refuses an explicit head chamfer that cannot be built as asked. Task 1 (tracer)
adds the head_chamfer rule to the bolt's explicit-conflict rule and proves it on the API, the CLI and
the parity test, with the page checked by hand at the end of the phase. Task 2 pins its edges: presets
(D-13), unusable values, a repeated key, a root path, the schema route and the equality at k / 2.

Purpose: L02, a direct conflict between things the user asked for is a 422 naming the fields, and a
dimension that can be trimmed without contradicting an explicit choice is capped and warned; only the
raw request knows which one this is (L13 D-25, 06.1 D-05). Output: the rule, its tests, and the
corrected docstrings.
</objective>
