## Phase Goal

ROADMAP **Goal** (verbatim): A bolt or screw (ISO 4014, ISO 4017) gets a chamfered hex head: one
`head_chamfer` field, an angle in degrees, default 30, where 0 builds the sharp head of today. The
chamfer is a cone from the inscribed circle `s / 2` on the top face only, the same stated model as the
nut face chamfer (L15, R4 a), so it clips the six corners; the bearing face is unchanged. The head's
closed form stays exact for the cone-clipped prism, the field ships on UI, API and CLI with its tests,
and a new decision-log entry supersedes L13 D-01's "no top chamfer".

<objective>
The decision is recorded where every agent reads it. Task 1 (tracer) writes L19, the entry every L19
citation in the code (the standing warning, the warnings, the sharp-head note, the field comment)
resolves to, and points L13 D-01 at it. Task 2 brings the architecture overview and the README's field
list up to date.

Purpose: `docs/architecture/decision_log.md` is the single source of locked decisions (CLAUDE.md); a
one-way default change without its entry would be a decision nobody can find. Output: L19, the L13
pointer, the overview and README edits.
</objective>
