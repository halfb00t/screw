## Phase Goal

ROADMAP Phase 8 goal (verbatim, not a user story): Close the gaps the v1.0 milestone audit found so the
first release ships with OPER-03 met: no admitted part ends in a kernel `422 build_error`, every build
path has a deadline or a logged reason it has none, and the front ends answer the same part the same
way.

This plan makes the cost model honest for the fine-swept parts (D-05) without moving anything at or
below a threshold (D-02).

<objective>
Fit `FINE_ENVELOPE` from the Phase 8 runner readings by F10, ship it through the emit-constants block,
switch `cost.fits` per part, and show that nothing drawn before Phase 8 and no shipped-sweep value moved.

Purpose: the fine sweep costs more time and STEP bytes than the shipped fit predicts; admission must
cover it or a fine part could pass its timeout or budget. Output: the judge, `fine-fit.json`, the
extended block, the sweep-aware `fits`, the checks and a RESULTS section.
</objective>
