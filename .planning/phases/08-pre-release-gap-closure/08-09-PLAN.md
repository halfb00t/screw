## Phase Goal

ROADMAP Phase 8 goal (verbatim, not a user story): Close the gaps the v1.0 milestone audit found so the
first release ships with OPER-03 met: no admitted part ends in a kernel `422 build_error`, every build
path has a deadline or a logged reason it has none, and the front ends answer the same part the same
way.

This plan lands D-01's second half, the guard, and files the residuals the sweep and the guard leave;
08-10 proves D-07 from the records and closes SC1 and OPER-03.

(D-19), and file as debt the three residuals the phase leaves (F13, A3, D-17).

Purpose: the fine sweep fixes most of the residual; the guard refuses, with the fields to change,
whatever it leaves (D-01, D-06). What neither proves is debt, not prose. Output: the guard and its
tests, three debt items with INDEX rows.
</objective>
