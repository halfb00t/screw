## Phase Goal

ROADMAP Phase 8 goal (verbatim, not a user story): Close the gaps the v1.0 milestone audit found so the
first release ships with OPER-03 met: no admitted part ends in a kernel `422 build_error`, every build
path has a deadline or a logged reason it has none, and the front ends answer the same part the same
way.

This plan was 08-08's second half, split off so each plan fits the context budget. 08-08 shipped
`FINE_ENVELOPE` as a constant; this plan makes admission read it, in the one commit that `make verify`
requires, and records F10 in RESULTS. It runs after 08-08 (wave 8) and before 08-09.

<objective>
Switch `cost.fits` to the fine envelope for fine-swept parts, show that nothing drawn before Phase 8 and
no runtime value beyond R21's count moved, and record the fine envelope in RESULTS.

Purpose: the fine sweep costs more time and STEP bytes than the shipped fit predicts; admission must
cover it or a fine part could pass its timeout or budget (D-05), while every part at or below a
threshold keeps its admission (D-02). Output: the sweep-aware `fits`, the F12 lift if needed, the
re-derived `runtime.json`, the re-pins and a RESULTS section.
</objective>
