## Phase Goal

ROADMAP Phase 8 goal (verbatim, not a user story): Close the gaps the v1.0 milestone audit found so the
first release ships with OPER-03 met: no admitted part ends in a kernel `422 build_error`, every build
path has a deadline or a logged reason it has none, and the front ends answer the same part the same
way.

This plan is the first of the OPER-03 chain (08-01, 08-03, 08-05, 08-12, 08-06, 08-07, 08-08, 08-13,
08-09, 08-10, in execution order). It writes every rule before any data, as Phase 7 did
(07-SWEEP-PROTOCOL.md R30), and sends the first walk. It runs alone in wave 1: 08-02 waits on it so
that no push changes the head the owner dispatches.

<objective>
Pre-register Phase 8's runner campaign: the band walk set that reads the shipped sweep where D-15's
bands are measured, the protocol that fixes every later rule, and the owner's go before the first
reading. Push the branch so the runner can build the dispatched commit.

Purpose: D-03, D-06 and D-15 read thresholds, band edges and ceilings from runner data (D-04), and
D-19 has the same walk re-read the shipped sweep outside the bands at d / pitch above 8. A bound is
credible only if its rule was fixed before its data. Output: `08-SWEEP-PROTOCOL.md`, the `band-walk`
generator, `bench/points/fine-bands.json`, an upstream branch, and a dispatched run id.
</objective>
