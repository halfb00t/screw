## Phase Goal

ROADMAP Phase 8 goal (verbatim, not a user story): Close the gaps the v1.0 milestone audit found so the
first release ships with OPER-03 met: no admitted part ends in a kernel `422 build_error`, every build
path has a deadline or a logged reason it has none, and the front ends answer the same part the same
way.

This plan lands D-01's kernel half: the fine sweep, the nut threshold and the bolt's route through the
predicate. 08-12 adds the measured bolt bands (it was this plan's second task, split off to keep each
plan inside the context budget); 08-06 reads both on the runner. From the commit 08-06 dispatches,
this plan's files are frozen (F11).

<objective>
Add the fine sweep as an argument of `helical.thread`, the kernel-free predicate that chooses it with
the nut threshold, both call sites, and the test that the island nuts build.

Purpose: SC1 wants every admitted in-wall part to build; option 2 of the debt does that above the
thresholds without moving any part at or below them (D-01, D-02). Only bolts inside the measured bands
take it (D-15, D-19), and those bands land in 08-12. Output: `uses_fine_sweep` with the nut threshold,
`fine=` in helical, both call sites, the kernel, spy, predicate and catalogue tests.
</objective>
