## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so no story is invented): The owner holds a bolt
and a nut printed from this tool at the default clearance that thread together by hand, and that
default and the printability threshold come from a recorded printed test, not from a forum or vendor
figure.

<objective>
The phase's one stop for rulings that do not depend on data (05-02 pattern). The research left eight
questions open; each is the owner's call, and each must be settled before the protocol is written (R1 to
R5) or before code reads it (R6 to R8), so none can be chosen after a result is known.

Purpose: the protocol and the later plans read their choices from one owner record. Output:
`06-OWNER-RULINGS.md`.

No tracer: this plan writes no code and builds no path; it is the decision record every later slice
reads. It runs beside 06-01 (that plan works only in its own worktree; this one writes one file in the
main checkout).
</objective>
