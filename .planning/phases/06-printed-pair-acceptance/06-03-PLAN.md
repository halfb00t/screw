## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so no story is invented): The owner holds a bolt
and a nut printed from this tool at the default clearance that thread together by hand, and that
default and the printability threshold come from a recorded printed test, not from a forum or vendor
figure.

<objective>
Finish the pre-registration and open it as PR A: the protocol (method, predictions, escape clause)
written on the pre-registration branch, the owner's print profile and predictions typed into it, a test
binding its text to the rule module, and the PR. Task 1 (tracer) writes the protocol and the test that
proves the protocol and the module state the same numbers. Task 2 is the owner typing the profile and
the predictions. Task 3 commits them, adds the no-slot guard and opens PR A.

it and lands it. Output: the protocol, its tests, one open PR.
