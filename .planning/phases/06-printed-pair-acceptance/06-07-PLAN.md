## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so no story is invented): The owner holds a bolt
and a nut printed from this tool at the default clearance that thread together by hand, and that
default and the printability threshold come from a recorded printed test, not from a forum or vendor
figure.

<objective>
D-09: one default for every size, and an honest warning where it was not measured. Task 1 (tracer) adds
the measured-range constants and the warning, wires it into `_nut`, and proves it on the CLI and the API
from the one producer. Task 2 corrects the comments and docs that still describe a required clearance.

Purpose: PAIR-02's "one absolute value" without a silent claim beyond M6 to M12. Output:
`screw.calc.printability`, the `_nut` insertion, its tests, the corrected text.
</objective>
