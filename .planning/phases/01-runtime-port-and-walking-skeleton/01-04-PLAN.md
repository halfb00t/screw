## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form — run `/gsd-mvp-phase 1` to restate it; not invented here): A user can generate a walking-skeleton bolt (`d`, `pitch`, `length`, plain unthreaded solid; an internal milestone, never released) from the web UI, the HTTP API and the CLI, all served by spur's ported runtime from one registered model, with front-end parity proven by one test over the registry.

<objective>
The web UI slice: a user opens the page, picks the kind (one entry, bolt), edits d/pitch/length
in a form generated from the schema, watches the 3D preview, reads the info panel, downloads
STL/STEP and copies a link that reopens the same part. The vendored three.js bundle is ported
with its reproducibility check.

Purpose: the third front end; after this plan all three serve the skeleton from one model.
Output: static/ (page, script, style, vendored bundle), web/ build, the static mount, the
vendor-bundle CI job.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL hash -> app.js | a shared link is untrusted input to the page |
| server text (warnings, titles, error msg) -> DOM | reflected content rendered in the browser |
| npm registry -> web/node_modules -> vendored bundle | third-party code the browser executes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-15 | T | app.js rendering of warnings, labels, errors | medium | mitigate | every node built with textContent/Object.assign; parity test in 01-05 asserts no HTML-string assignment in app.js |
| T-01-16 | T | hash kind= naming an unregistered kind | medium | mitigate | navigate() refuses an unknown kind with an error naming it and builds nothing |
| T-01-17 | T | vendored three.js bundle | medium | mitigate | byte-identical rebuild from the committed lockfile (`make vendor-check`, CI vendor-bundle job); no npm update; `npm ci` only |
| T-01-SC | T | npm installs in web/ | high | mitigate | three and esbuild are copied pins from spur's lockfile (research verdict: esbuild OK, three SUS only for the newest publish, not 0.186.0); `npm ci` refuses a lockfile drift; no new package |
</threat_model>
