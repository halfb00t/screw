## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form — run `/gsd-mvp-phase 1` to restate it; not invented here): A user can generate a walking-skeleton bolt (`d`, `pitch`, `length`, plain unthreaded solid; an internal milestone, never released) from the web UI, the HTTP API and the CLI, all served by spur's ported runtime from one registered model, with front-end parity proven by one test over the registry.

<objective>
Container delivery: the skeleton runs from an image whose dependency closure is resolved in
linux/amd64 and proven by the smoke test at build time, and from `docker compose` on localhost
with labelled interim limits. `make check` becomes the local copy of everything CI runs.

Purpose: success criterion 3's "make check passes"; after this plan a user can `make up` and use
the skeleton from a container.
Output: Dockerfile, compose.yaml, .dockerignore, docker/refresh-requirements.sh, the regenerated
runtime closure, Makefile container targets, the CI image job.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-20 | E | container runtime | medium | mitigate | uid 10001, read_only root, cap_drop ALL, no-new-privileges, tmpfs /tmp bounded at 256m |
| T-01-21 | S | network exposure without authentication | medium | mitigate | compose binds 127.0.0.1 only, with spur's comment to put authentication in front before exposing it (spur debt no-authentication carried by reference) |
| T-01-22 | D | container OOM kills every worker and the parent | medium | mitigate | INTERIM mem_limit 4g plus the D-14 bound (worst measured corner ~1.05 GiB per worker); Phase 7 re-sweeps |
| T-01-23 | T | closure drift with --no-deps | medium | mitigate | refresh script resolves fresh and runs docker/smoke.py; the Dockerfile runs smoke again at build; never hand-edit requirements.txt |
| T-01-24 | T | GitHub Actions pinned by tag, not SHA | low | accept | inherited from spur's workflow unchanged; out of this phase's scope |
| T-01-SC | T | packages resolved by refresh-requirements.sh | high | mitigate | no new runtime package: the closure resolves pyproject.toml's existing ranges (cadquery, fastapi, pydantic, uvicorn); smoke proves it |
