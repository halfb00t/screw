## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form — run `/gsd-mvp-phase 1` to restate it; not invented here): A user can generate a walking-skeleton bolt (`d`, `pitch`, `length`, plain unthreaded solid; an internal milestone, never released) from the web UI, the HTTP API and the CLI, all served by spur's ported runtime from one registered model, with front-end parity proven by one test over the registry.

<objective>
The CLI slice: a user can run `screw info bolt`, `screw export bolt -o bolt.stl` and
`screw serve` — every flag generated from the registered model, every bad value or foreign flag
refused naming it, the web layer never imported.

Purpose: the second front end on the one model; after this plan a user without a browser gets
the same part and the same document the API serves.
Output: cli.py, __main__.py, the `screw` entry point, contract 3, tests/test_cli.py, README usage.
</objective>
