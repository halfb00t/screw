## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form — run `/gsd-mvp-phase 2` to restate it; no story
is invented here): The owner knows, from a pre-registered and recorded measurement rather than a
guess, which helical construction to build, which volume estimator to trust, what turn cap each
size needs, and whether a kernel pair proof can be made falsifiable, all before any field that
builds a thread exists.

<objective>
The tracer: one rod row runs end to end through every layer the campaign uses — quiet gate, run
header, kernel-free closed form, the sewn-twist builder in a worker subprocess, precise volume and
the stdlib STL check, the JSON-lines record, the kernel-free classification, the Markdown report and
the JSONL file — then the pre-registration guard that refuses every campaign run until the protocol
is on `origin/main`.

Purpose: prove the process split (kernel only in the child, oracle and verdict in a kernel-free
parent) and the guard on the first commit, before ten more modules are layered on them.
Output: `bench/quiet.py`, the `bench/thread_spike/` package (9 modules), the import-linter contract,
`make bench.thread`, tests.
</objective>
