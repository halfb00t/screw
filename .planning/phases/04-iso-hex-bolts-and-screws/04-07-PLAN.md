## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so no story is invented here): A user picks
"M6 × 20, ISO 4017" (or an ISO 4014 size and length) and gets a hex head bolt or screw whose
explicit millimetre fields were filled from a cited, tested table row, with an info panel whose every
number traces to a field or a row.

<objective>
The first cited rows, behind every gate the owner ruled. Tables land as a leaf with contracts 6 and 7
in the same commit (CLAUDE.md, overview "each in the commit that adds the module it guards"),
double-entered (D-14), scanned for UNVERIFIED (D-15), typed so a row without a Source fails mypy
(TABL-02). The first thing they make visible (the info document's `preset` and `designation`) is plan
04-08, split from this plan on the seam between table infrastructure and the info keys.

Purpose: lay the table architecture on one size before transcribing 300 rows, and prove the import
boundary that lets a link rebuild without a table (SC2) at runtime, which import-linter alone cannot
see (Alert 3).
Output: `src/screw/tables/`, the owner copy of the M6 lines, contracts 6 and 7, the gates.

Scope: one task, one atomic commit of 12 files, none separable: the five package modules; contracts
6 and 7 in `pyproject.toml` (CLAUDE.md: a module's import-boundary contract lands in the commit that
adds it); the three owner TSVs the double-entry diff reads (rows, owner copy, diff, scan and control
land together, RESEARCH Pitfall 4); and the three test files (new behaviour ships with its tests). No
debt file is touched here.
</objective>
