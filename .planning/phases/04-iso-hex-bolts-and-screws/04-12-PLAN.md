## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so no story is invented here): A user picks
"M6 × 20, ISO 4017" (or an ISO 4014 size and length) and gets a hex head bolt or screw whose
explicit millimetre fields were filled from a cited, tested table row, with an info panel whose every
number traces to a field or a row.

<objective>
A user picks a preset on the API and the CLI: one catalogue document, served by `GET /api/presets`
and printed by `screw presets`, and `--preset <id>` on `screw info` and `screw export` that fills the mm
fields and lets explicit flags win. The model routes stay mm-only; the parity test learns `--preset`
by a positive rule.

Purpose: TABL-01 on two of the three front ends (the page is plan 04-13, built from this document),
THRD-03's preset fill, D-10 and D-11.
Output: the route, the subcommand, the flag, the round-trip and parity tests, README examples.
</objective>
