## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so no story is invented here): A user picks
"M6 × 20, ISO 4017" (or an ISO 4014 size and length) and gets a hex head bolt or screw whose
explicit millimetre fields were filled from a cited, tested table row, with an info panel whose every
number traces to a field or a row.

<assumption_delta_decision>
Detector (assumption-delta scan, phase 4): `detected: true`, signals `pluralization` ("second-choice
sizes") and `chosen` ("custom").
- Primary noun: the explicit millimetre parameter set of the one `bolt` kind (`BoltParams`), carried
  by the URL. ISO 4014 and ISO 4017 are two standards over that one kind, not two kinds; a standard
  is reported from a matching row and the preset id is page-session metadata only (D-09).
  Decision: `no-change` — the mm fields were promoted to the primary identity in Phase 1 (L09) and the
  preset stays demoted (Anti-Pattern 2).
- Derived -> chosen: the thread length was derived (the whole `length`, Phase 3 rod) and becomes the
  explicit field `thread_length`. Decision: `promote` — `thread_length` is a field; "threaded to the
  head" is demoted to the ISO 4017 preset's value (`thread_length = length`) and the default 20.0.
- Invariant test (accepted, plan 04-12): every catalogue row round-trips through `BoltParams.model_validate(fields)`
  and `derive` to an exact match of its own id (ISO 4017 on a tie).
</assumption_delta_decision>

read it (D-22). This is one atomic change: the field, the builder, `derive` and every test the new
field breaks land in one commit, so `make verify` stays green (RESEARCH Pitfall 4).

Purpose: THRD-03 and the 4014 half of TYPE-01's geometry, with L02's rule that a default below an
explicit length is built and warned. Split out of this slice, on their natural seams: the 422 for two
explicit values at the request boundary (D-25) and the short-thread info warning (IN-01) are plan
04-05; the bench corpus pin and its README are plan 04-06.
Output: the field, the shank, `built_thread_length`, the caps on t, the rows and warnings, the ripple
tests.
</objective>
