## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so no story is invented here): A user picks
"M6 × 20, ISO 4017" (or an ISO 4014 size and length) and gets a hex head bolt or screw whose
explicit millimetre fields were filled from a cited, tested table row, with an info panel whose every
number traces to a field or a row.

Gap G-04-3 (04-UAT.md, test 3; the owner's ruling on 04-REVIEW IN-02, option a, 2026-10-12): the
page's Download STL link always asks for the fine STL, which the INTERIM 64 MiB export cap refuses
for the long ISO 4017 presets (D-21, L13), so a fifth of the picker's rows end in a JSON 422 on the
primary action. The page may not read the warning to know (D-10).

<objective>
The info document gains a structured download state, per format and quality, computed by the same
`download_refusal` the model routes and `screw export` use; the page builds both download links from
it and offers `Download STL (preview)` where the fine STL is refused, the STEP link unchanged and the
warning kept; `screw info` prints the same member; `01-UI-SPEC.md` and L13 say so.

Where the label text lives (read off 04-13): static page copy stays in `index.html` (the anchors'
`Download STL` and `Download STEP`, like the `ISO preset` legend), and the part of a label that
depends on the part comes from the server (the entry's `quality`, like the picker's `axes`). The page
composes `<static label> (<quality>)` and holds no copy of its own for it. The exact strings are
`Download STL`, `Download STEP` and `Download STL (preview)`; the parity tests pin all three.

Purpose: TABL-01 and TYPE-02 as a user sees them: every preset the picker offers downloads on its
primary action. Output: `Download` and `PartInfo.downloads` in calc, `setDownloads(q, downloads)` in
app.js, tests on calc, API, parity and presets, the UI contract, L13, the review disposition and one
idea item.
Estimate: raw 90000 tokens against the 100000 smart-zone budget (confidence low, uncalibrated: the
calibration query reports 0 samples, factor 1).

| T-04-28 | Tampering | the download href composed from the server's `format` and `quality` | low | mitigate | both are `Literal` enums on `Download`, pinned to the model route's `fmt` and `quality` enums in OpenAPI by tests/test_api.py; `quality` is written with `URLSearchParams.set`, so it is encoded; index.html must hold an anchor for every route format (label test) |
