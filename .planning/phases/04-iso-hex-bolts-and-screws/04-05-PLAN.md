## Phase Goal

ROADMAP **Goal** (verbatim; not in user-story form, so no story is invented here): A user picks
"M6 × 20, ISO 4017" (or an ISO 4014 size and length) and gets a hex head bolt or screw whose
explicit millimetre fields were filled from a cited, tested table row, with an info panel whose every
number traces to a field or a row.

<objective>
The refusals and warnings `thread_length` adds at the edges, split from plan 04-04 on its natural
seam: two explicit values in conflict are a 422 naming both, decided at the request boundary on the
API and the CLI by one shared rule (D-25); a thread too short to build gets a warning and no numbers
(the IN-01 debt item, which says "revisit when the info document next changes").

Purpose: L02's "a direct conflict between two things the user asked for is a 422 naming the fields"
for `thread_length` against `length`, through the mechanism the owner ruled (D-25), and INFO-03's
"no honest value means a warning and no number".
Output: `thread_length_conflict`, the API dependency, the CLI check, the parity test, the short-thread
warning, the IN-01 item resolved.

Scope: 12 file paths, of which three are the IN-01 debt item's resolution: its active and resolved
paths (one file moved by `git mv`) and the INDEX row. CLAUDE.md requires a debt item's resolution to
land in the same commit as its fix, which is Task 2's, so they cannot move to another plan or commit;
without them the plan touches 9 files.
</objective>
